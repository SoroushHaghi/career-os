# Synthetic knowledge consolidation demo

This example demonstrates the public, data-free cross-session knowledge path.

It uses two synthetic session syntheses that discuss the same concept. The consolidator:

- merges the repeated concept into one stable course concept;
- deduplicates repeated details;
- preserves the contribution from each session/version;
- retains uncertainty;
- keeps evidence references and source-version lineage;
- labels the result as unverified derived knowledge.

Run:

```bash
npm run demo:knowledge
```

No external model, API key, private source, or personal data is required.
