# Career OS v1 documentation (frozen)

These documents describe the first version of Career OS (2026): a multi-step session protocol, a
role registry and routing protocol, a Google Apps Script ingestion runtime, a knowledge compiler,
the "vNext" redesign plan and its monitor page.

They are kept unchanged for reference. **They are not the current rules.** The current system is
described in `../ARCHITECTURE.md`, `../SETUP.md`, `../WORKFLOWS.md` and `../../templates/memory-repo/`.
Why v1 was replaced: `../ARCHITECTURE.md`, section "Lessons from v1".
