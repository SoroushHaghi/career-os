# AI project instruction (paste into each project)

Leave the project's knowledge files empty. Paste one line, the same in every AI tool (Claude,
ChatGPT, Gemini …). Only the memory repo and the workspace change:

```
Before replying, read RULES.md in SoroushHaghi/career-os and follow it exactly. Memory: <owner>/<memory-repo>. Workspace: <workspace>
```

Always include the workspace, also for the whole-system project (`Workspace: SYSTEM`): explicit is safer
for weaker models. The same line goes into the root `AGENTS.md` of a project's own repository. For a new
project the agent gives you this line filled in. Why so short: the rules are written once in `career-os`, your data
and settings live in your memory repo — improving either never means editing your projects.
