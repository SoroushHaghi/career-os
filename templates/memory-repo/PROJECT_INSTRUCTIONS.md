# AI project instruction (paste into each project)

Leave the project's knowledge files empty. Paste one line, the same in every AI tool:

```
Before replying, read AGENTS.md in <owner>/<memory-repo> and follow it exactly. Workspace: <workspace>
```

For the whole-system project leave out ` Workspace: …` (the default is `SYSTEM`). For a new project the
agent gives you this line filled in. Why so short: every rule, the read order and your personal
preferences live in the repository, so improving a rule never means editing several projects.
