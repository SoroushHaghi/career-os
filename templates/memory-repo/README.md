# Memory repository template

Copy this folder into a new **private** repository. Start with `docs/SETUP.md` in `career-os`.

| File | Purpose |
|---|---|
| `AGENTS.md` | rules for every AI agent |
| `CLAUDE.md`, `GEMINI.md` | one-line pointers (each tool reads its own file name) |
| `PROJECT_INSTRUCTIONS.md` | the four lines to paste into each AI project |
| `SYSTEM/CORE.md` | one-page context about you |
| `SYSTEM/BACKLOG.md` | parked system ideas |
| `WORKSPACES/_TEMPLATE/` | copy once per course / language / search |
| `labels.json` | Issue labels for records (applications, leads …) |
| `.github/` | automated privacy and size checks on every push |
